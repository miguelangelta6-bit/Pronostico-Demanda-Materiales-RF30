# Datos

`simulada/eventos_simulados.csv` contiene registros totalmente inventados para ilustración y pruebas.

**Nunca subas** un CSV operativo o comercial a este repositorio público. Si vas a ejecutar el código con información real, almacénala dentro de `data/privada/` (ignorada por Git), valida permisos de uso y elimina identificadores sensibles.

Consulta el diccionario en `docs/diccionario_datos.md`.
